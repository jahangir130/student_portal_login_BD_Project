ADMIN ROLE + PASSWORD VISIBILITY UPDATE

PASSWORD VISIBILITY
- Added Show/Hide buttons to password fields across login, registration and admin/teacher forms.
- Password values remain password-masked until the user clicks Show.
- Passwords continue to be stored using password_hash() and checked with password_verify().
- Plain-text passwords are never stored or displayed by the application.

ADMIN ROLES — ALL THREE CAN LOG IN
1. Super Admin
   - Dashboard, students, teachers, routines and Admin Panel.
   - Can create additional Admin accounts.
2. Admin
   - Dashboard, students, teachers and routines.
   - Cannot open Admin Panel or create another Admin.
3. Routine Manager
   - Dashboard and routine management only.
   - Cannot open student, teacher or Admin Panel pages.

SECURITY
- Role authorization is enforced server-side, not only by hiding sidebar links.
- Direct URL access to restricted pages returns HTTP 403.
- Admin login normalizes role capitalization/spacing to support existing role labels.
- Unknown role values are not allowed to sign in.
- First Admin created by setup_admin.php receives Super Admin role.

IMPORTANT FOR EXISTING DATABASES
- No schema migration is required; admins.role already exists.
- Ensure each account's admins.role is one of: Admin, Routine Manager, Super Admin.
- If an account has a different role text, Super Admin can update that row's role in phpMyAdmin.
- This update does not reset any account password.
- Keep existing database; do not re-import database.sql.

PASSWORD RECOVERY / LOGIN
- If a password is forgotten, it cannot be read back because it is hashed.
- A Super Admin must set a new password through a secure reset workflow or a controlled database update.
- All three roles sign in through the same admin_login.php page with their own email/password.

TESTING
- PHP CLI syntax validation was run on all project PHP files after this update.
- Live database login and permission tests must still be run in the user's XAMPP environment.

ADMIN PANEL LOGIN ACCESS UPDATE
- Admin Panel now explains the shared admin login URL and how each admin signs in.
- Each administrator uses their own email and password at admin_login.php.
- Added Reset Password action for each admin. Only Super Admin can access this page.
- Resetting replaces the password hash; the previous password cannot be recovered or viewed.
- Local login URL shown: http://localhost/student_admin_portal_v2/admin_login.php
